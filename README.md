# Cybersec Backend Web API (C# / .NET 8)

A RESTful backend Web API built with C# and ASP.NET Core (.NET 8), structured around clean software architecture and secure request handling.

## Key Engineering Features
* **Modular Architecture:** Separates concerns across `Controllers`, `Services`, `Data`, `Models`, and Data Transfer Objects (`Dto`).
* **Custom Middleware & Helpers:** Implements request pipeline logic, object mapping, and structured data validation.
* **Database Integration:** Configured with Entity Framework migrations (`Migrations/`) and local SQLite persistence (`blog.db`).
